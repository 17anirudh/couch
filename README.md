## Overview

- Kurma is a determinstic AI powered resume tailoring platform that uses your CV as the source of truth and tailors resume taking job information. 
- Produces latex converted pdf for high ATS parsability along with summary of ATS Scoring and related information for maximum information.
- Automatically saves each session as a tracking sheet for carrer tracking

## Tech Stack

- Python, Typescript
